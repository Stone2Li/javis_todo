## 3. 版本门禁与执行环境

- R0：M01–M04独立验收完成，无网络核心任务可用。
- R1：M05–M08通过；真实支持Provider可调用，两端语音能力有设备记录。
- R2：M09–M11与上述22项全部通过；数据迁移、灾难恢复、隐私、成本、安全问题关闭；平台审核通过才成为商业发布。
- R3：M12与M14的Memory/Reflection/项目摘要通过；覆盖功能章节全部P0；未提及任务自动完成、未确认覆盖、预算超限三类问题不得带入发布。
- R4：按M13/M14增强搜索/M15逐模块发布，平台入口缺少准入时关闭并明确说明。

执行层：Linux CI运行contracts、fixtures、后端、账本并发与AI fake集成；macOS/Xcode运行iOS编译/测试及可用模拟器旅程；DevEco匹配的主机运行Harmony构建与测试框架；真机负责ASR、Key、系统入口、后台恢复、商店和性能。测试命令在工程初始化后按实际工具写入CI，当前不虚构可执行命令。

设备矩阵最低建议：iOS最低支持版本与当前稳定版本，至少2台性能层次不同的iPhone；HarmonyOS最低与当前目标商用版本，至少2台不同性能档真机。每端覆盖无麦克风授权、无通知授权、低存储、无网络、深色/大字体、中文输入与屏幕阅读器。模拟器可补覆盖，不能替代实机。
