# 07 平台适配、探针与可选画像

## M00：分平台的最小可行性验证

M00不是一个必须“所有项目全通过才允许开发”的总闸门。先做宿主/构建探针；其余验证只阻塞相应生产适配器或发布。每项记录工具chain版本、OS/API、设备型号、代码SHA、步骤/实际结果、限制与证据文件，不用网页说明冒充真机通过。

| 子包 / 门禁 | 探针 | 影响的后续工作 |
|---|---|---|
| M00a 工程能力 | 检查Mac/Xcode或替代构建安排；DevEco/CLI/商用SDK；创建最小包；目标设备安装 | 影响该端adapter/UI运行，不阻塞语言无关契约和fake协议测试 |
| M00b ASR | 中文能力/模型安装/本地或云端数据流/权限/长短模式 | 阻塞M07真实能力声明，不阻塞文字Capture |
| M00c Secret/HTTP | 保存/取用/删除/锁屏、SSE/取消/TLS/origin | 阻塞真实BYOK，不阻塞ScriptedProvider |
| M00d 商业 | 开发者主体、商品类型/¥3价格、付费下载证据/恢复/退款、BYOK审核规则 | 阻塞生产M09/M10和商店发布，不阻塞R0 |
| M00e 数据 | SQLite/ArkData CRUD/事务/迁移/中文搜索/文件生命周期 | 阻塞真实M02验收，内存用例可并行设计 |
| M00f 系统入口 | 原生Widget/ArkUI卡片展示与一条轻操作、实况场景条件 | 只影响M15与对应可选功能 |
| M00g 大陆模型/运营 | 地域/主体、API/数据政策、真实费用上界、服务可关闭 | 阻塞真实Hosted profile与商业发布，不阻塞本地规则 |

当前事实：用户报告iPhone iOS26，Mate30系统5.x/6.x，Mac另行补充，无开发者账号；完整OS/API与HAP安装尚无证据。探针必须读实际系统，不自行把Mate机型推断成已支持/已不支持。

## 1. iOS适配

| Port | 实现候选 | 必测行为 |
|---|---|---|
| Persistence | SQLite+GRDB候选（锁版本/许可证）；SwiftData不是默认跨端模型 | actor/线程使用、事务、迁移、WAL一致性备份 |
| AITransport | URLSession原生HTTP/stream | 字节边界、取消、错误体脱敏、后台切换、origin隔离 |
| SecretStore | Keychain，解锁/本机访问策略 | 锁屏失败可解释、不跨设备同步、删除生效、普通备份无Key |
| Speech | iOS26 SpeechAnalyzer及按能力fallback | isAvailable/语言/模型/权限，旧Speech边界；不静默发送音频到云 |
| Purchase | StoreKit AppTransaction；IAP如另经产品决策 | shared失败、用户refresh、签名环境、稳定主体与退款分离 |
| FilePicker | 系统文件/照片选择器，复制到私有目录 | 选择取消/授权变动/云端占位文件/低空间；不申请无关全库权限 |
| Focus/Notification | 持久时刻+系统通知、可选ActivityKit | 无授权仍计时、进程恢复；通知/实况不代表常驻执行 |

最低覆盖版本暂以iOS17候选保留，但不为文档方便宣称已确定；iOS26增强在能力判断后启用。Xcode/SDK版本、deployment target与App Store提交要求是三件事，M00a分别记录。当前宿主是Linux不能承担iOS签名真机验证；也不假定它已安装Swift工具链。

免费Personal Team可做受限个人设备测试；7天等限制要计入手工重装和数据备份流程，不能误认为App Store购买恢复已验证。正式TestFlight/发布/付费业务需对应开发者资格与后台配置。

## 2. HarmonyOS适配

ArkTS+ArkUI+Stage为目标；商用SDK模块名、最低API与设备SystemCapability以M00固定结果为准。不能把OpenHarmony master里更高API的例子当候选API12都支持，也不把旧Android APK方案算完成原生目标。

| Port | 实现候选 | 必测行为 |
|---|---|---|
| Persistence | ArkData relationalStore | 事务API/读写连接限制、分页、迁移、中文tokenizer |
| AITransport | Network Kit requestInStream等按目标API | 状态码与ArrayBuffer流分开、dataEnd/取消/监听清理 |
| SecretStore | Asset Store SECRET；超长Key用HUKS管理加密密钥 | byte范围、alias无秘密、锁屏与卸载行为按实际版本验证 |
| Speech | Core Speech Kit | 长短模式/PCM格式/实时输入、中文、离线/网络与费用范围 |
| Purchase | 商用原生购买adapter | 个人主体、商品、凭证、公钥链/服务器验证、恢复和退款 |
| Card | ArkUI Form Kit、FormExtensionAbility | 允许模块、事件/数据更新、App不运行、快照陈旧 |
| Live surface | Live View Kit，可选 | 场景资格、模板/权限、更新/结束、用户关闭与过期 |

DevEco公开页有Windows/macOS要求及新CLI/Linux模拟器介绍；这不证明当前Linux实例可以完整构建、签名、运行商用工程。M00a实际验证CLI/SDK下载、license、签名与目标包后才能登记能力，不能仅凭npm包安装成功打勾。

## M15 系统入口模块

### 共享展示快照

App提交数据后发布`SystemSnapshot {schemaVersion, snapshotRevision, generatedAt, planDate, zoneId, redactionLevel, recommendedTask?, nextTasks[0..3], focusSummary?}`。只包含展示所需最小字段，不含笔记、Key、原始语音、购买证明。锁屏默认隐藏敏感标题或按用户偏好显示。

snapshotRevision是单调的发布序列，不等于每个Task的revision。快照中的可操作项需各自带taskId/taskRevision；系统操作必须核对真实任务版本。

本地文件写临时文件再原子替换；iOS可用App Group受控容器，鸿蒙通过允许的卡片数据接口发布。卡片不直接读取完整业务数据库。快照发布失败时保留旧快照与更新时间，App下次启动/数据变化重试。

### 子包

| 子包 | 默认交付 | 验收 |
|---|---|---|
| M15a 只读入口 | iOS桌面/锁屏Widget，鸿蒙桌面卡片，点击深链 | App未运行、旧快照、换日、无数据、深色/字体/锁屏脱敏 |
| M15b 轻操作 | 完成/推迟/进入Focus的统一App命令 | 幂等、过时revision、任务删除、受锁保护、不能绕过确认 |
| M15c 快捷入口 | App Intents/Shortcuts/系统Controls按版本；鸿蒙可用入口 | 不支持时隐藏；深链参数白名单，不执行任意URL指令 |
| M15d 专注显示 | Live Activities/实况窗在准入通过后启用 | 主动结束、系统/用户移除、长时间到期；显示结束不偷偷改Session |

V1最低实现是**展示+回App完成动作**。直接后台完成仅在验证原生执行环境可调用同一用例、持久化并核对revision后启用；不能为了实现卡片按钮另造一套SQL。需要编辑、录音、同意或冲突处理时明确打开App，不在卡片运行完整LLM。

Widget动态预算与Live Activity时效约束已在调研记录，不承诺每秒重载或永久活跃。App Intents静默执行的权限/可用性按实际target测试，不通过则保持显式回App操作。

## M16 可选个性化

**输入：**用户自愿的精力/偏好、计划接受/调整、Session与估时差异的最小本地摘要。**输出：**可解释且有版本的UserPreference建议，不直接改截止/依赖/用户锁定。

子包：M16a本地偏好与重置；M16b建议提案/确认；M16c对照评测。默认不上传工作画像，不采集其他App列表或隐藏设备指纹。无足够数据返回基础规则；取消同意/重置清理派生画像与缓存，不清除任务历史。

独立验证：固定反馈序列→可解释偏好变化→重置恢复基础规则；冷启动未知、反馈稀疏、时区旅行不产生假结论。它不阻塞R2/R3，任何“更容易进入心流”的宣传需用户研究证据，不能把接受率单项当心理效果证明。

## 3. 功能门禁与开发开关

开关分为compile-time Debug demo、设备能力、用户偏好、服务端运营四种。生产开关不能关闭购买验签/预算/确认保护来“临时修复”；远程配置只能收紧模型/额度或关闭Hosted，不能远程静默打开录音/改Provider。

能力结果有UNKNOWN/AVAILABLE/UNAVAILABLE/NEEDS_PERMISSION/NEEDS_ASSET，带reason与checkedAt；网页资料只记录文档支持，实际AVAILABLE必须来自设备探测与成功操作。Release页面不展示“已实现”但永远无法完成的按钮。
