## 本阶段交付

- M01a：Task/Project、UUID/revision/估时/日期/时区、Deadline序列化、Unicode标量标题验证。
- M01b：任务/项目状态、阻塞原因、完成/重开/归档恢复、DAG与引用、依赖override理由。
- M01c：捕获时区/基准时刻、有限中文日期、模糊日期保留、DST的23/25小时日界和不存在的当地日期拒绝。
- M01d：值快照预览/确认、版本冲突、同批聚合只增一次revision、重复ID重放保护、事件草稿、补偿撤销及后续编辑冲突。
- 独立执行器：共享fixture输入→Swift实际领域规则→规范化JSON结果，非零用例且失败返回非零。

这是**Swift端首版领域核心**。鸿蒙端同规则实现仍待移植，不能标记双平台M01全部完成。数据库的UoW/实际持久化与并发原子性属于M02，尚未实现；UI、AI、支付和语音也未实现。
